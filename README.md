# 微零记 · 三国寻踪

三国读书知识库网站 —— 给孩子讲三国时的伴读工具：故事、人物、地图、对话、典籍五个入口，共用同一套带出处标注的内容数据。

策划方案见 `docs/三国读书内容网站-策划方案.md`，对标作品的逐帧拆解见 `docs/三国图志视频逐帧拆解.md`。

## 运行

零依赖，只需要 Node.js ≥ 18：

```bash
npm run build     # content/*.json → data/site.json（含构建期校验）
npm run serve     # http://127.0.0.1:4173
npm test          # 无头浏览器渲染 + 交互自检（需本机 Chrome）
```

自检脚本：

- `scripts/build-content.mjs` — 内容编译与校验（字段完整、人物引用、出处三分法）
- `scripts/smoke-test.mjs` — 不依赖浏览器的数据/路由渲染自检
- `scripts/interaction-test.mjs` — Chrome DevTools 协议逐页渲染 + 关键交互（星图选中、章节筛选、对话年份边界）验证

## 目录

```
content/   内容源（120 回目录 catalog、人物/关系/事件/史料 master、地名/年表/时期 world）
data/      构建产物 site.json、search-index.json、build-report.json
assets/    样式与零依赖 ES Modules（app/pages/ui/star-map/scroll-map）
docs/      策划方案、视频逐帧拆解、预览截图与素材
scripts/   构建、本地服务、自检
```

## 当前实现范围（P0 + 内容扩容）

- **首页**：今日一回 + 五入口导览
- **故事馆**：120 回索引、27 篇已校回目导读（其余显示占位）、赤壁之战专题（多立场视角）
- **人物馆**：146 人档案（汉室/群雄/蜀汉/曹魏/孙吴/西晋六阵营）、关系列表、足迹；**群英星图** Canvas 球面自转、点击置中、关系连线按出处着色，支持年份滑块与人物页直达（`#/star?person=xx&year=207` 只显示当年已登场人物与已成立关系）
- **山河年表**：手绘山水绘卷 SVG + 年份拖动 + 双人足迹叠加（不接入在线底图，不含行政边界与真实经纬）
- **对话台**：按人物时期限定知识边界（207 年的诸葛亮不知道赤壁结局），19 个对话时期，不依赖大模型
- **典籍室**：演义回目 × 史料条目双索引，出处三分法（关系统计：正史 123 / 演义 10 / 传说 6）
- **全站搜索**、关于页（底本与版权、实现范围声明）
